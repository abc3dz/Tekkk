## CONTROLS
Keyboard / Game-pad
WASD / Left Stick or D-pad = Movement
J / West = Attack
K / South = Jump 
L / East = Dash 
I / North = Power 
ESC / Start = Pause 
Q / LT2 = Status 
O / RT2 = Control 
----------------
Guardian dialog
----------------
Left Menu
-----------
W / ArrowUp / DPadUp = Up
S / ArrowDown / DPadDown = Down
Space / South = Confirm
Esc / Start = Close dialog
-------------------------
Element Allocation Panel
-------------------------
W / ArrowUp / DPadUp = Select element (Up)
S / ArrowDown / DPadDown = Select element (Down)
U / RightTrigger = Increase element value
E / LeftTrigger = Decrease element value
A / ArrowLeft / DPadLeft = Select left attack element
D / ArrowRight / DPadRight = Select right attack element
Enter / East = Confirm attack element
